Follow-up: give these `RequestLimits.Action` and extend the rule (a verb list, or "the bound type has no collection member").

Measured: the admitted host reports port 5000 (Kestrel's default address) while the plain host gets an ephemeral port, because `UseKestrel(0)` is called on the factory returned by `WithWebHostBuilder`. This PR's 413 proof runs on that host. It fails closed (two admitted hosts in parallel, or anything else on 127.0.0.1:5000, give "address already in use", reproduced with a second admitted test class), so no false pass, but the comment "a free loopback port" is untrue for this mode and a second admitted test class would break the suite. Follow-up: configure the port on the derived factory (or set the URL to `http://127.0.0.1:0` in the builder) and assert `Port != 5000`.
