# HASM — Accounting & Inventory Management

HASM (حسم) is a modular accounting and inventory management system.

## Technology Stack
- Frontend: React + TypeScript
- Desktop: Tauri 2
- Backend: ASP.NET Core (C#)
- Database: PostgreSQL

## Repository Structure
- `docs/` — Requirements and architecture documentation
- `src/` — Application source code (planned)
- `tests/` — Automated tests (planned)

## Project Status
Requirements consolidation and architecture validation.

## Development Policy
- The `main` branch contains reviewed changes.
- New work is developed on feature branches.
- Changes are integrated through pull requests.
- Implementation starts after SRS approval.
